🤖 文本模型配置（可添加多个，支持默认切换与故障转移）

每条配置对应一个 OpenAI 兼容 的模型接口（填入各平台官方的 Base URL、模型名、你自己的 API Key）。 配置只保存在本机浏览器，不做任何加密，请仅在你本人可控的设备上使用。
注意：这里需要各平台官方开放的 API Key，无法读取你在网页端的登录态 / Cookie / 会话，也不会替你抓取任何已登录页面。

📱 虚拟号平台接入（预留）

为「艺术挪车码」接入运营商副号 / 隐私虚拟号做准备。配置后，隐私中转模式会先把真实号码绑定到虚拟号，再把虚拟号编码进二维码。 建议自建一层适配网关统一接口：网关需实现 POST /bind， 请求体 {mode, phoneA, expire}， 响应 {virtual_number}（阿里隐私号 AXN、移动和多号等都可包一层转换）。未配置时自动使用内置 AES 加密中转，同样不暴露真实号码。
说明：网关地址与密钥仅保存在本机；生成码时由你的浏览器直接调用网关。平台侧产生的副号费用与实名要求以运营商规则为准。
